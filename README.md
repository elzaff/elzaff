## 🧑‍💻 About Me

I'm **Fazle Mawla Wahyuhanda**, a data science & machine learning enthusiast from Indonesia 🇮🇩.
I love turning messy real-world data — satellite imagery, tweets, traffic sensors, piles of trash photos — into models that actually work.

- 🔭 Currently working on **package quality classification** and **paddy field segmentation** for data competitions
- 🏆 Regular participant in data competitions: **SATRIA DATA**, **Datavidia**, **BDC**, **Holology**, **ARA**, **DATASCAPE**
- 👁️ Main playground: **Computer Vision** (classification, detection, segmentation) and **Indonesian NLP**
- 📈 Also into **time-series forecasting**, **graph ML**, and **explainable AI**
- 🛠️ Sometimes I build web stuff too — like a mobile-first cash dashboard and a FastAPI backend
- ⚡ Fun fact: I have probably spent more time staring at validation loss curves than at the sky ☁️
